✨ New Features Added

1. Landing Page PDF Button
Added "Generate sample PDF" button in the top navigation bar for instant PDF generation from the landing page.
2. Dual Format Generation
The drawing generation now produces both DXF and PDF formats simultaneously when uploading parameter workbooks.
3. Export Panel PDF Download
Added PDF download button in the export panel alongside the existing DXF download option.
4. API Endpoint for Sample PDF
New `/api/generate_sample_pdf` endpoint that generates a sample PDF using the simple_12m template.
5. Enhanced Error Handling
Improved PDF conversion with robust fallback mechanisms for text rendering issues.
📝 Note: The frontend development environment requires network access for npm dependencies. For production deployment, ensure proper network configuration or use pre-built assets.
